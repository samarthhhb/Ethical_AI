# Ethical_AI
Using synthetic data highlighting user interaction with LLMs to identify weather LLMs will use personal information for vulnerability identification. Ethics are a robust and important part of any AI solution much like human life. As we transition from basic AI tools and softwares to robust, 'Neuromorphic' and advanced AI tools and software: Ethics are required more than ever!

To tackle these issues I wanted to explore that the convinience of any LLM just knowing me, can it be used against me? Here I try the same by using synthetic data generated from LLMs which describes the interaction log between an user and an AI. This log was then visualised and processed.

I used Logistic Regression based model to predict if a user is at risk i.e. vulnerable or not for an AI exploit based on conditions where the values of certain characteristics is higher than their 75th Quantile.

Refer to the attached ipynb file for all the details and related comments and text!
